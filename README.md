# raytracer

Very basic raytracer. You can find a demo [here](https://raytracer.pages.dev). It might
not work on all browsers, since it requests quite a large texture allocation upfront.
I tested it on Firefox on Linux.

![demo screenshot showing settings panes and two objects](https://apeiros.xyz/assets/projects/raytracer.webp)

I made this a long time ago when I was first learning graphics programming, so there's no
acceleration structure and it's quite unoptimized, but it was still a valuable educational
experience for me, since I hadn't done any shader programming or OpenGL before this.

I also never got around to implementing glass, but I'm planning to do that in a
[new project](https://github.com/Apeiros-46B/mirage).
